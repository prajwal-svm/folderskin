# 分享皮肤包时你需要同意的条款

第 2 版。

分享皮肤包，意味着你的图片会以你的名义，公开且永久地展示给所有 FolderSkin 用户。在把皮肤包送进审核队列之前，FolderSkin 会请你确认下面的条款。服务会把你同意的条款版本和皮肤包一起记录下来，这样维护者就能看到你同意了什么、是什么时候同意的。

这些不是建议。违反其中任何一条的皮肤包都会被拒绝，发布后才发现违规的皮肤包会被移除。

## 图片必须是你有权分享的

1. **图片是你做的，或者你有权分享**。皮肤包里的每张图片都是你亲手画的、渲染的、拍摄的，或者以其他方式制作的，又或者每张图片都是 CC0，或采用允许你以这种方式分享的许可协议，而且这一点你亲自核实过，而不是想当然。
2. **图片不是从别处拿来的**。不是取自其他应用，不是取自游戏，不是取自图库，不是取自别人的作品集，也不是从搜索结果里扒下来的。“我在网上找到的”不等于获得了许可。
3. **AI 生成的图片也适用同样的规则**。如果图片是模型生成的，你要对两件事负责：模型的条款是否允许你分享生成结果，以及你没有让它模仿在世艺术家的风格或现有的角色。
4. **署名必须是你自己的**。皮肤包署的是你的 FolderSkin 名字，也就是你的电脑验证时登记的名字，而不是 GitHub 账号，而且这个名字必须是你有权使用的。
5. **你选择的许可协议真实有效，且不可撤销**。皮肤包一经发布，大家就会依据该许可协议使用这些图片。对于已经流传出去的副本，你之后无法收回授权。

## 图片中不得包含的内容

6. **不得有色情内容**。不得有裸露、性行为、带性暗示的图像或恋物内容，无论经过怎样的风格化或卡通化处理。
7. **不得有任何将儿童性化的内容**。任何在性相关情境中描绘未成年人的内容都会上报有关部门，而不只是拒绝了事。不存在“艺术意图”或“风格化”的例外。
8. **不得有涉及自我伤害的内容**。不得描绘、美化或鼓励自杀、自残或进食障碍，包括宣扬这些行为的群体所使用的符号。
9. **不得有仇恨内容**。不得有侮辱性称呼、仇恨符号，也不得因种族、民族、国籍、宗教、种姓、生理性别、社会性别、性取向、残障或其他类似特征而攻击或贬低他人。
10. **不得有血腥或惊悚内容**。不得有露骨的暴力、肢解，或真实的伤亡画面。
11. **不得骚扰任何人**。不得有针对特定个人的内容，不得包含任何人的个人信息，不得出现未同意入画的人。可辨认出身份的真人，必须获得本人许可。
12. **不得有违法内容，也不得为违法行为提供帮助**。包括武器、毒品，或在你或 FolderSkin 用户所在地违法的任何其他事物的操作指引、宣传或品牌标识。
13. **不得使用他人的品牌**。不得使用属于他人的标志、商标或角色，也不得把皮肤包做得像是某家公司或某个人推出的官方皮肤包，除非对方确实提出过这样的请求。
14. **文件中不得有任何欺骗性内容**。文件就是图片。里面不得藏有任何东西，不得伪装成别的东西，也不得试图骗过检查。

## 之后会发生什么

15. **由维护者决定**。皮肤包可能因上述任何原因被拒绝，也可能因为不太合适、质量不高，或与已有皮肤包几乎重复而被拒绝。我们没有义务发布任何内容。
16. **之后也可能被移除**。皮肤包发布后，如果出现任何问题（许可协议问题、用户举报，或上述条款中的任何一项），皮肤包会被直接移除，无需等待讨论。
17. **内容公开，而且会被保留**。皮肤包一经发布，皮肤包本身、其中的图片和你的 FolderSkin 名字都是公开的，而且皮肤包仓库会保留历史记录，所以即使皮肤包之后被移除，也请默认所有发布过的内容都会永久存在。
18. **验证过的电脑只能你自己用**。从这台电脑发送的皮肤包，都会署上它验证时登记的名字。不要用别人的电脑发送皮肤包，也不要把你的密钥分享给别人：FolderSkin 保存的恢复文件就是这把密钥。

## 举报皮肤包

如果已发布的皮肤包违反了上述任何条款，请在[皮肤包仓库](https://github.com/prajwal-svm/folderskin-community/issues)提交一个 issue，并附上这个皮肤包的链接。凡是涉及儿童的内容，也请同时向有关部门举报：在美国请向 NCMEC 的 [CyberTipline](https://report.cybertip.org/) 举报，在其他地区请向警方或你所在国家的相关举报热线举报。

## 条款变更

如果条款有变化，顶部的版本号会随之提高。你所同意的，是你提交皮肤包时随之记录下来的那个版本。
